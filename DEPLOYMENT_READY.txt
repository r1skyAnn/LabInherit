  🚀 如何部署到生产服务器
================================================================================

方式一：快速部署（15 分钟）
--------------------------
参考文档：docs/QUICKSTART_DEPLOY.md

1. 安装依赖：
   sudo apt install -y python3.12 nodejs npm mysql-server nginx git

2. 配置数据库：
   sudo mysql -e "CREATE DATABASE labinherit; ..."

3. 克隆代码：
   cd /opt && git clone YOUR_REPO_URL labinherit

4. 配置环境变量：
   cp backend/.env.production.example backend/.env
   nano backend/.env  # 修改 DB_PASSWORD、JWT_SECRET、SMTP_*

5. 一键部署：
   ./deploy/deploy.sh

6. 配置 Nginx + HTTPS：
   sudo cp deploy/nginx/labinherit.conf /etc/nginx/sites-enabled/
   sudo certbot --nginx -d your-domain.com

7. 验证：
   ./deploy/healthcheck.sh

方式二：Docker Compose（本地测试）
---------------------------------
cd deploy
docker compose up -d
